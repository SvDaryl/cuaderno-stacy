Ecuación cuadrática

Resolver x² + bx + c = 0 es buscar dónde la parábola cruza el eje x. Puede cruzarlo dos veces, una o ninguna.

Arrastra la parábola (agárrala de cualquier lado): su vértice va a donde lleves el dedo.

Las tres formas de resolverla

Factorizando con aspa simple: x² − 5x + 6 = (x − 2)(x − 3) = 0 → x = 2 o x = 3. Con la fórmula general, que siempre funciona:

x = (−b ± √Δ) / 2a    con   Δ = b² − 4ac

El discriminante Δ decide cuántas soluciones reales hay: Δ > 0, dos; Δ = 0, una (doble); Δ < 0, ninguna. Es lo mismo que ves en la gráfica de la función cuadrática.

Suma y producto de raíces

Si x₁ y x₂ son las raíces de ax² + bx + c = 0, no hace falta hallarlas para saber su suma y su producto:

x₁ + x₂ = −b/a · x₁ · x₂ = c/aAl revés: si conoces la suma S y el producto P, la ecuación es x² − S·x + P = 0.
Raíces 4 + √5 y 4 − √5
S = 8 · P = 16 − 5 = 11
Ecuación: x² − 8x + 11 = 0 → b = −8, c = 11

Truco de concurso: con S y P también sacas otras cosas, como 1/x₁ + 1/x₂ = S/P o x₁² + x₂² = S² − 2P.
