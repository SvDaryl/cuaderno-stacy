Productos notables

Hay multiplicaciones que salen tanto que vale la pena saberlas de memoria. Y todas se pueden ver como áreas.

Arrastra sobre el cuadrado para cambiar dónde termina a y empieza b.

Los que más se usan

(a + b)² = a² + 2ab + b²Binomio al cuadrado: no olvides el doble producto.
(a − b)² = a² − 2ab + b²Igual, con el doble producto restando.
(a + b)(a − b) = a² − b²Suma por diferencia: los términos del medio se cancelan.
(x + m)(x + n) = x² + (m + n)x + mnProducto de binomios con término común. Al revés, es el aspa simple.
(a + b)³ = a³ + 3a²b + 3ab² + b³Binomio al cubo.
(a + b)² = a² + 2ab + b²Legendre: (a + b)² + (a − b)² = 2(a² + b²) y (a + b)² − (a − b)² = 4ab.

Para qué sirven

Sirven para calcular rápido (99² = (100 − 1)² = 10000 − 200 + 1 = 9801) y, sobre todo, para factorizar: si reconoces un producto notable “desarrollado”, lo puedes volver a juntar. Por ejemplo, (a + b)⁴ − (a − b)⁴ es una diferencia de cuadrados: [(a + b)² + (a − b)²][(a + b)² − (a − b)²] = 2(a² + b²) · 4ab = 8ab(a² + b²).

Otro truco de concurso: si te dan a + b y ab, sacas a² + b² sin hallar a y b: a² + b² = (a + b)² − 2ab.
